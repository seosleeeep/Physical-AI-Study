# ROS 2 Launch를 이용한 로봇 생성 및 컨트롤러 자동 실행

## 1. 개념

ROS 2 Launch: 여러 노드와 실행 프로그램을 하나의 명령으로 실행, 실행 순서를 관리.
*rgbd.launch.py에 구성함.

| 구성 요소 | 역할 |
|---|---|
| Gazebo | 시뮬레이션 환경 실행 |
| robot_state_publisher | URDF를 읽어 로봇 설명과 TF 제공 |
| ros_gz_sim create | Gazebo에 차량 생성 |
| joint_state_broadcaster | 바퀴의 위치·속도 등 관절 상태 발행 |
| diff_drive_controller | 차량 속도 명령을 좌우 바퀴 속도로 변환 |

gz_ros2_control
: 차량의 관절을 ROS 2 제어 시스템에 연결. 컨트롤러가 활성화되면 주행 명령을 받을 수 있음.

## 2. 구현 과정

### 2.1 파일 구성

작업 패키지: ~/jazzy_car_ws/src/simple_car

```text
simple_car/
├── launch/
│   └── rgbd.launch.py
├── urdf/
│   └── car_rgbd.urdf
└── config/
    └── controllers.yaml
```

- `car_rgbd.urdf`: 차량 구조, 관절 및 제어 플러그인 정의
- `controllers.yaml`: 컨트롤러 종류와 바퀴 설정
- `rgbd.launch.py`: Gazebo 실행, 차량 생성 및 컨트롤러 활성화 자동화

### 2.2 로봇 설명 읽기

```python
share = Path(get_package_share_directory("simple_car"))

robot = (share / "urdf/car_rgbd.urdf").read_text()
robot = robot.replace("$(find simple_car)", str(share))
```

설치된 패키지 경로에서 URDF를 읽고, URDF에 사용된 패키지 경로 표현을 실제 경로로 바꾼다.

```python
state_publisher = Node(
    package="robot_state_publisher",
    executable="robot_state_publisher",
    parameters=[{
        "robot_description": ParameterValue(robot, value_type=str),
        "use_sim_time": True,
    }],
    output="screen",
)
```

`robot_description`에 URDF 내용을 전달한다. `use_sim_time=True`는 Gazebo의 시뮬레이션 시간을 사용하도록 설정한다.

### 2.3 Gazebo 실행 및 차량 생성

```python
gazebo = IncludeLaunchDescription(
    PythonLaunchDescriptionSource(
        str(gz_share / "launch/gz_sim.launch.py")
    ),
    launch_arguments={
        "gz_args": LaunchConfiguration("gz_args"),
        "on_exit_shutdown": "true",
    }.items(),
)
```

`IncludeLaunchDescription`으로 Gazebo의 기존 Launch 파일을 포함한다.

```python
spawn = Node(
    package="ros_gz_sim",
    executable="create",
    arguments=[
        "-world", "empty",
        "-topic", "/robot_description",
        "-name", "simple_car",
        "-z", "0.2",
    ],
    output="screen",
)
```

`create`는 `/robot_description`에서 차량 설명을 받아 Gazebo에 모델을 생성한다.

| 인자 | 의미 |
|---|---|
| `-world empty` | 생성할 월드 이름 |
| `-topic /robot_description` | 차량 설명을 읽을 토픽 |
| `-name simple_car` | Gazebo 모델 이름 |
| `-z 0.2` | 초기 생성 높이, 0.2m |

### 2.4 컨트롤러 자동 실행

```python
joint_states = Node(
    package="controller_manager",
    executable="spawner",
    arguments=[
        "joint_state_broadcaster",
        "-c", "/controller_manager",
        "--controller-manager-timeout", "60",
    ],
    output="screen",
)

drive = Node(
    package="controller_manager",
    executable="spawner",
    arguments=[
        "diff_drive_controller",
        "-c", "/controller_manager",
        "--controller-manager-timeout", "60",
    ],
    output="screen",
)
```

`spawner`는 지정한 컨트롤러를 로드하고 설정한 뒤 활성화한다. `-c`는 사용할 컨트롤러 관리자이고, timeout은 관리자 연결 대기 시간을 지정한다.

컨트롤러 종류는 `controllers.yaml`에 정의했다.

```yaml
controller_manager:
  ros__parameters:
    update_rate: 100
    use_sim_time: true

    joint_state_broadcaster:
      type: joint_state_broadcaster/JointStateBroadcaster

    diff_drive_controller:
      type: diff_drive_controller/DiffDriveController
```

주행 컨트롤러에는 네 바퀴의 관절 이름과 차량 치수를 전달했다.

```yaml
diff_drive_controller:
  ros__parameters:
    left_wheel_names:
      - front_left_wheel_joint
      - rear_left_wheel_joint
    right_wheel_names:
      - front_right_wheel_joint
      - rear_right_wheel_joint

    wheel_separation: 0.38
    wheel_radius: 0.09
```

`wheel_separation`은 좌우 바퀴 사이 거리, `wheel_radius`는 바퀴 반지름이며 단위는 m이다.

### 2.5 실행 순서 지정

```python
RegisterEventHandler(
    OnProcessExit(
        target_action=spawn,
        on_exit=[joint_states],
    )
),

RegisterEventHandler(
    OnProcessExit(
        target_action=joint_states,
        on_exit=[drive],
    )
),
```

정상 실행 시 다음 순서로 진행된다.

```text
차량 생성 프로그램 종료
    → joint_state_broadcaster 로드·활성화
    → diff_drive_controller 로드·활성화
```

`OnProcessExit`는 프로그램의 종료를 감지하는 기능이다. 종료 자체가 성공을 보장하지는 않으므로, 실행 후 컨트롤러 상태를 별도로 확인했다.

## 3. 실행 및 검증 결과

### 3.1 Launch 실행

기존 시뮬레이션을 종료한 뒤 다음 명령을 실행했다.

```bash
source /opt/ros/jazzy/setup.bash
source ~/jazzy_car_ws/install/setup.bash

ros2 launch simple_car rgbd.launch.py
```

두 `source` 명령은 ROS 2와 작업 공간의 실행 환경을 불러온다. Launch 실행으로 Gazebo에 차량을 생성하고 컨트롤러를 자동으로 활성화했다. 같은 파일에 포함된 센서 bridge와 RViz도 함께 실행된다.

### 3.2 컨트롤러 상태 확인

새 터미널에서 다음을 실행했다.

```bash
source /opt/ros/jazzy/setup.bash
source ~/jazzy_car_ws/install/setup.bash

ros2 control list_controllers
```

실제 출력은 다음과 같았다.

```text
diff_drive_controller   diff_drive_controller/DiffDriveController      active
joint_state_broadcaster joint_state_broadcaster/JointStateBroadcaster  active
```

list_controllers
:현재 상태를 조회하는 명령(컨트롤러를 실행하는 명령X)

두 컨트롤러가 모두 `active`로 표시되어, 별도의 수동 활성화 명령 없이 Launch 파일에서 컨트롤러가 자동으로 활성화됨을 확인했다. 앞서 방향키 조종으로 활성화된 주행 컨트롤러가 차량 속도 명령을 받아 동작하는 것도 확인했다.
